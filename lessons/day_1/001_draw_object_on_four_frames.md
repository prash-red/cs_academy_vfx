# Day 1 — Session 2: Draw an Object Across 4 Frames

This session gives students a simple hands-on exercise in visual storytelling and motion. They will sketch the same object in four different frames of a short video clip to explore how an object appears to change with motion and perspective.

## Lesson goal

By the end of this session, students should be able to:

- observe how an object changes across multiple frames of video;
- sketch the same object in different positions or viewpoints;
- connect drawing with the idea of animation and motion in VFX.

## Activity

1. Give a sequence of four frames.
2. Ask students to choose an object to composite.
3. Have them draw that object in each of the four frames, paying attention to:
   - position;
   - scale;
   - orientation;
   - motion cues.
4. Discuss how the object appears to move or shift between frames.

## Discussion prompts

- How did the object change from frame to frame?
- What clues helped you place it correctly?
- How does this exercise relate to animation and visual effects?
