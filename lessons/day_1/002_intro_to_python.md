# Day 1 — Session 3: Intro to Python

This session gives students their first hands-on introduction to programming. Working
in a Colab notebook, they will write and run real Python code for the first time,
building up from printing text to using variables, conditionals, lists, and loops.

## Lesson goal

By the end of this session, students should be able to:

- run and edit code cells in a Google Colab notebook;
- use `print()` to display text and values;
- create variables and understand basic types (strings, integers, floats);
- use math operators to combine and compare values;
- write an `if` / `elif` / `else` statement to make a decision in code;
- create a list and loop over it with a `for` loop.

## Suggested pacing (45–60 min)

1. Colab basics — what a cell is, running with Shift+Enter (5 min)
2. `print()` and strings (5 min)
3. Variables and basic types (10 min)
4. Math operators (5 min)
5. Conditionals: `if` / `elif` / `else` (10 min)
6. Lists (5 min)
7. `for` loops (10 min)
8. Wrap-up mini challenge (5–10 min)

## Discussion prompts

- Where else have you seen a computer make a decision like an `if` statement does?
- How might loops and lists be useful for working with video frames, like in our
  drawing exercise?
